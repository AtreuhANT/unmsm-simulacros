Dispositivo Móvil No Permitido

El sistema de evaluación y supervisión biométrica de la UNMSM requiere estrictamente una computadora de escritorio o laptop con cámara web activa y teclado físico.

  • ✓ PC de escritorio o Laptop (Windows, macOS o Linux)
  • ✓ Cámara Web funcional (para reconocimiento facial Edge)
  • ✓ Navegador moderno (Google Chrome, Microsoft Edge o Firefox)
  • ✓ Pantalla completa obligatoria sin interrupciones

Por favor ingresa desde tu computadora personal para rendir tus simulacros de admisión.
